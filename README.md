# Apache-Spark-PySpark
This project perform data analysis by using PySpark. A comparative between PySpark and Pandas is also shown.


## 🚀 How to run locally
1. Clone this repository:
```
git clone https://github.com/arteaga7/Apache-Spark-PySpark.git
```
2. Set virtual environment and install dependencies:
```
python3 -m venv env && source env/bin/activate && pip3 install -r requirements.txt
```
3. Run "pyspark1.ipynb"
